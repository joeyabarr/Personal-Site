The Local Shelf

Designing a marketplace for local sellers

The idea is to provide a marketplace for finding farm stands, cottage bakeries, and other independent sellers. I’m building guest discovery with storefronts that sellers can make their own.

MARKETPLACE ARCHITECTURE

Start with guest discovery

The public landing page gives shoppers a way to explore sellers before making an account. I built the landing page and sign-in and registration interfaces while exploring how buyer and seller accounts fit that experience.

Separate the web app and API

I set up a pnpm and Turborepo workspace with a Next.js frontend, a Fastify API, and a shared Prisma database package. The initial Postgres model connects shops to owners. That relationship gives the API a starting point for deciding who can manage each shop.

Plan storefronts with custom domains

I want sellers to be able to use a platform subdomain or bring a domain they own. The design maps each storefront hostname to the same shop ID, so the domain can change without moving the shop’s data. Custom domains and the authentication backend are still in development.
